# 产品中心

1.7.0：左侧“仓储打印规则”集中维护实物资料、库存关联、打印规则和数字贴条件；旧产品中的规则自动汇总展示，原产品资料不改写。新建/批量新建可直接选择仓库囤货（原现货）、打印定制或定制订单，按产品统一选规则，新增规格自动沿用，也可在供货与规则逐个SKU调整。规则有独立保存和版本校验，引用中的规则不能直接移除；更新后须重新预览同步到仓库。统一规则改价影响当前预计成本，已确认历史订单与实物余额不重算。新图片最大500KB，缩略图仍最大30KB。

1.6.0：V3计价资料与自动SKU成本。现货仓库的实物资料可选择“按总价换算”（计价数量、计价单位、单位换算数量、货品总价）或“直接填单价”。计价数量不增加库存。默认SKU按实物单价和每份消耗计算，固定整份成本作为显式特殊模式。切换自动模式清除旧整份成本缓存，打包费不在此重复计算。单位成本保留8位小数，已确认历史订单成本不随新价格重算。数字贴按实际版面计算，打印成本走整单实际核定。前端同步仓库前显示已有单价变化；仓库补录后可“取回仓库补录成本”，预览差异并确认更新共享实物的所属产品。旧资料、库存余额和历史订单不在升级时迁移或清空。

新版空白模板下载 /warehouse-template-v3.xlsx。灰色公式列为预览，后端按输入和关联独立重算，不信任手填结果。旧版表头仍可解析，旧手工成本保留固定整份成本语义。工作流程：表格整理后导入现货仓库，勾选后预览同步到星辰仓库管理，再由仓库盘点。

1.5.0：编辑产品新增“仓库与打印”，按SKU配置现货、打印定制、现货优先（按条件），并维护实物、消耗关联、打印规则、数字贴条件。主页或编辑页下载V2 Excel范本；填完从“导入表格”导入，保存后可勾选产品并“同步已选到新城”，预览确认后才写入仓库。供货配置不同于实际库存，仓库人员仍需盘点数量。数字贴超范围、库存不足只建议整单打印，需人工确认；未盘点和歧义资料先人工核对。共用配置编码只在所属产品维护，其他产品引用，避免重复修改。

同步只建立或更新商品与规则资料，不覆盖已盘点数量和历史实际成本。已有独立成品SKU或不同实物关联会拒绝同步并要求先核对，不会自动改写旧库存关联。资料删除不会自动删除仓库货品。新配置使用直接同步；原CSV导出保留为旧资料兼容入口。服务端可通过PRODUCT_CENTER_WAREHOUSE_URL指定仓库固定地址，默认http://122.51.235.103:8003，浏览器不能指定接收地址。

自有服务器可部署的产品资料库。Python 3.10及以上，图片处理依赖Pillow 12.3.0；先运行 `python -m pip install -r requirements.txt`。

在Windows双击“启动产品中心.cmd”，打开 http://127.0.0.1:8002。也可以运行 `python app.py`。默认仅允许本机访问。

产品资料保存在 `data/products.sqlite3`，图片在 `data/uploads`，导入记录在 `data/imports`（Excel保留解析资料及字段，原表请另外保管）。网页刷新、关闭浏览器不会删除资料。修改编辑表单后需要点击“保存产品”，图片上传后同样需要保存关联。

产品支持图片上传、多规格、搜索筛选、复制、删除、回收站与恢复。导出仓库CSV使用现有仓库新品模板字段；导出网站ZIP包含通用商品CSV及图片，不包含内部成本、负责人或运费。该ZIP需要按目标网站的字段要求导入，不会自动上架。

销售SKU保持与ERP商家编码一致。每份包装含量与实物库存数量分开。产品库不保存、不修改仓库库存。共用库存的实际扣减规则继续由仓库维护。

Excel导入按工作表建立产品档案，保留源工作表及行号。只展开明确合并单元格，不按空白猜测成本。无法识别的字段留空，导入预览展示警告。重复导入同一文件不会创建重复产品。不同文件中重复SKU会保留该行并清空冲突编码，供人工核对。库存方式需要人工选择，不能按编码后缀推测。

完整备份同时包含数据库、图片和导入记录。可从页面底部下载，备份中不包含有效登录会话。恢复时先停止服务，再用备份覆盖指定数据目录。建议保留数据库及图片的定期离机备份。

服务器运行前设置管理密码：`python app.py --set-password`。设置 `PRODUCT_CENTER_REQUIRE_AUTH=1` 强制登录。使用 `PRODUCT_CENTER_PUBLIC_URL=https://你的域名` 指定访问地址，再运行 `python app.py --host 127.0.0.1 --port 18004`，通过反向代理对外提供服务。上传请求体上限建议20MB。非本机绑定会强制要求密码。HTTPS下登录Cookie自动启用Secure。

数据目录通过 `PRODUCT_CENTER_DATA` 指定。升级代码时不覆盖此目录。`deploy/` 提供自有服务器的独立服务示例，部署前调整域名和目录。仓库及新品工作台无需修改。

当前为单个管理密码的初版，尚无员工独立账号、直接推送仓库接口和目标网站专用适配。已有仓库SKU通过仓库当前规则跳过，新品更新需在仓库核对处理。

所有手动上传、Excel嵌入图片和离线批量导入使用相同压缩策略：每张实际保存不超过500,000字节。原图限15MB/4800万像素，小图不放大；大图优先高质量WebP，必要时逐步缩小尺寸，保留比例及透明背景。动图保留动态效果，压缩时最多60帧。服务端验证真实内容并再次检查大小。每款最多200张，规格可关联自己的图片；Excel图片只按实际锚点及明确合并单元格关联。

列表与相册使用独立缩略图：最长边384px、每张不超过30,000字节，保留比例及透明背景。详情封面和导出仍使用不超过500,000字节的大图。所有新图片保存时同步生成缩略图；旧图片由批量任务补齐，缺失缓存可按需重建。缩略图在data/thumbnails，备份一并包含。列表默认每页30个，桌面5列、宽屏6列，勾选位于图片下方；状态保留在编辑页及列表视图，卡片图上不显示状态角标。

删除与回收站（1.3.0）：编辑页“删除产品”先移入回收站，产品图片和规格保留，可恢复。回收站支持单个彻底删除和清空全部，均展示确认清单；清空时核对全部产品版本，清单变化时拒绝执行。彻底删除释放SKU编码并清理该产品事件及独占图片/缩略图，其他正常或回收站产品共用的图片保留。仓库资料不受影响。历史独立备份继续保留。

批量新建（1.4.0）：首页点击“批量新建”，填写产品名、款数、数量规格、两级SKU前缀，按款式×数量生成规格。中文首拼在本系统内由pypinyin 0.55.0生成，可手动修正；不调用外部拼音服务。款式A至Z后延续AA、AB。生成字段可独立修改并保留，↺恢复统一规则；减少规格前确认，临时移除行可在本次编辑中恢复。每款上传或选择一张图片会应用到该款各数量规格，可取消共享单独选图。规则和单格覆盖随产品保存，重新打开后可继续同步；不自动修改已有历史产品。最多200款、50种数量、合计1000行，SKU冲突阻止保存。

批量编辑（1.4.1）：上方不再设置统一尺寸。在规格第一行输入尺寸、整份成本、销售价，会同步到未单独修改的后续批量行；单格修改和清空均保存为独立值，后续改首行不会覆盖，新增款式跟随当前首行默认值，↺可恢复跟随。支持一次选择/拖入多张图片，按顺序填充空款式；款式之间拖动交换图片，文字、SKU和尺寸不变，同款所有数量规格更新。多余图片保留在可折叠素材区，拖动或点击可重新分配；图片仍执行500KB压缩及缩略图处理。

本次图片与供货调整：新上传、表格导入图片统一不超过500,000字节，缩略图仍不超过30,000字节；既有图片不放大、不重新压缩。供货方式增加定制订单，用于每单修改姓名等内容的产品；同步后需仓库核对定制内容并人工确认整单打印，不自动扣现货。
